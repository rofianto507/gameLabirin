# Panduan Desain Karakter (versi lanjutan, dari foto anak)

Versi awal game memakai **bola berwarna** (Xhaka biru, Razkhan oranye). Panduan ini untuk
mengganti bola dengan karakter dari foto nanti.

## Sudut pandang
Tampak 3/4 dari atas (seperti game petualangan klasik): wajah tetap terlihat.

## Dari foto jadi karakter
1. Pilih foto jelas, wajah menghadap depan.
2. Ambil **3 ciri khas saja** (potongan rambut, kacamata/gigi ompong, warna baju).
3. Gaya kartun: kepala besar (~1/2 tinggi badan), badan mungil, mata besar bulat, hidung/mulut sangat sederhana.
4. Maksimal 4-5 warna utama, warna datar tanpa gradasi rumit.
5. **Garis tepi tebal** gelap (#263238) agar terbaca di semua latar.
6. Hindari baju berwarna sama dengan latar dunia: hijau murni (Hutan), biru-ungu pekat (Gua), putih (Awan).

## Spesifikasi
| Hal | Saran |
|---|---|
| Format | PNG latar transparan |
| Kanvas | 256 x 256 px |
| Ukuran di layar | sekitar 70-80 px |
| Posisi | kaki di tengah bawah, konsisten |
| Nama berkas | `nama_arah_aksi.png`, mis. `razkhan_depan_diam.png` |

Minimal 5 gambar per anak: depan, belakang, samping kanan (kiri = balik kanan), senang, "boing" (mata terpejam).
Versi lebih bagus ~11 gambar (tambah 2 pose melangkah per arah).

## Kuna
Badan bulat kecil, sayap transparan, perut menyala kuning keemasan, lingkaran cahaya lembut.
Ekspresi: biasa, senang (opsional: menunjuk arah).

Gunakan gaya yang sama (tebal garis, mata, proporsi) untuk kedua anak dan Kuna.
